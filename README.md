# FORTEX SRL — Catálogo online

Sitio estático de catálogo de productos con buscador, filtros y carrito.

## Publicar con GitHub Pages

1. Creá un repositorio en GitHub, por ejemplo `fortex-catalogo`.
2. Subí `index.html` a la raíz del repositorio.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que GitHub Pages publique el sitio. La dirección aparecerá en esa misma sección.

## Importante

Los precios del catálogo son ejemplos. Cambialos por los precios reales antes de publicar.
El carrito calcula el subtotal, pero no procesa pagos reales.
